# CodePilot

## In tre righe
È un client desktop multipiattaforma per agenti di codice, con chat, Git, terminale e provider diversi. [README](https://github.com/op7418/CodePilot/blob/1ae6d76de6993377dab961eacf04927babd99eb1/README.md#L4-L10)
Si rivolge a chi vuole usare Claude Code, Codex o modelli via API da un'unica applicazione locale. [README](https://github.com/op7418/CodePilot/blob/1ae6d76de6993377dab961eacf04927babd99eb1/README.md#L47-L80)
Rispetto al profilo Topics descritto nel brief, il suo punto forte è l'aggregazione di runtime e provider, 17+ dichiarati; una board generale di task non è documentata. [README](https://github.com/op7418/CodePilot/blob/1ae6d76de6993377dab961eacf04927babd99eb1/README.md#L47-L60) · [README](https://github.com/op7418/CodePilot/blob/1ae6d76de6993377dab961eacf04927babd99eb1/README.md#L139-L149)

## Sessioni e task
- Una conversazione sceglie directory di lavoro, modalità Code/Plan/Ask e modello; l'interfaccia pubblicizza pausa, ripresa, rewind, archivio e due sessioni affiancate. [README](https://github.com/op7418/CodePilot/blob/1ae6d76de6993377dab961eacf04927babd99eb1/README.md#L115-L126) · [doc: https://www.codepilot.sh/docs/chat](https://www.codepilot.sh/docs/chat)
- Ogni messaggio utente è descritto come punto di rewind; la conversazione conserva la scelta del provider. [doc: https://github.com/op7418/CodePilot/blob/1ae6d76de6993377dab961eacf04927babd99eb1/apps/site/content/docs/en/chat.mdx#L78-L104](https://github.com/op7418/CodePilot/blob/1ae6d76de6993377dab961eacf04927babd99eb1/apps/site/content/docs/en/chat.mdx#L78-L104)
- Mentre una risposta è in corso, i nuovi messaggi entrano in una coda per sessione e partono in sequenza al termine dello stream; la coda resta associata alla sessione anche se si cambia vista. [codice: src/components/chat/ChatView.tsx:627-643](https://github.com/op7418/CodePilot/blob/1ae6d76de6993377dab961eacf04927babd99eb1/src/components/chat/ChatView.tsx#L627-L643) · [codice: src/components/chat/ChatView.tsx:1438-1473](https://github.com/op7418/CodePilot/blob/1ae6d76de6993377dab961eacf04927babd99eb1/src/components/chat/ChatView.tsx#L1438-L1473)
- Un worktree Git può essere creato dal pannello e collegato a una nuova conversazione; il pannello mostra percorso, branch e stato modificato. [doc: https://github.com/op7418/CodePilot/blob/1ae6d76de6993377dab961eacf04927babd99eb1/apps/site/content/docs/en/git-and-workspace.mdx#L129-L143](https://github.com/op7418/CodePilot/blob/1ae6d76de6993377dab961eacf04927babd99eb1/apps/site/content/docs/en/git-and-workspace.mdx#L129-L143) · [codice: src/lib/git/service.ts:328-399](https://github.com/op7418/CodePilot/blob/1ae6d76de6993377dab961eacf04927babd99eb1/src/lib/git/service.ts#L328-L399)
