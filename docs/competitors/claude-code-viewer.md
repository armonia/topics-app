# Claude Code Viewer

## In tre righe
- È un client web self-hosted per avviare, seguire e consultare sessioni di Claude Code, con i log sul computer che ospita il server. [README](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/README.md#L9-L20)
- Il suo punto più forte rispetto a Topics è l’accesso remoto già rifinito: interfaccia mobile, PWA, notifiche push, terminale e Git nello stesso client. [README](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/README.md#L82-L95), [README](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/README.md#L193-L208)
- È centrato sulle sessioni di un solo agente, Claude Code: non documenta la board globale multi-agente, la gestione di worktree o il ciclo automatico review-merge-publish di Topics. [README](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/README.md#L177-L210)

## Architettura
- Il backend separa controller e servizi tramite Effect Context, mentre le rotte Hono validano i payload; questa è la struttura principale dell’API. [docs/dev.md](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/docs/dev.md#L13-L22)
- Conteggio sul clone shallow al commit `9367cf0`: 41.541 righe in 410 file TypeScript, 21.831 righe in 136 file TSX, 300 righe JavaScript. Sono inclusi i file di test; non risultano sorgenti Rust o Go. [snapshot del repository](https://github.com/d-kimuson/claude-code-viewer/tree/9367cf006be9965c954e6cd36526f2195dce67ea)
- Client React 19 con Vite, TanStack Router e Query, Jotai, Radix UI e Tailwind. [docs/dev.md](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/docs/dev.md#L5-L22), [package.json](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/package.json#L70-L85)
- Server Node.js con Hono e Effect-TS; il client browser parla con API HTTP, SSE per gli eventi e WebSocket per il terminale. Non è un’app Tauri e non usa Bun. [docs/dev.md](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/docs/dev.md#L13-L22), [sseRoutes.ts](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/src/server/hono/routes/sseRoutes.ts#L10-L20), [terminalWebSocket.ts](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/src/server/terminal/terminalWebSocket.ts#L65-L94)
- I transcript originali restano JSONL sotto `~/.claude/projects`; una cache SQLite locale conserva indici e metadati. La cache usa WAL e FTS5, non sostituisce i log. [README](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/README.md#L232-L247), [DrizzleService.ts](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/src/server/lib/db/DrizzleService.ts#L13-L32), [schema.ts](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/src/server/lib/db/schema.ts#L7-L45)
- Il server scopre il binario `claude` dal PATH o da un percorso configurato e usa `@anthropic-ai/claude-agent-sdk` per inviare prompt e leggere gli eventi della sessione. [ClaudeCode.ts](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/src/server/core/claude-code/models/ClaudeCode.ts#L40-L106), [ClaudeCode.ts](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/src/server/core/claude-code/models/ClaudeCode.ts#L169-L208)
- Quindi l’integrazione principale è l’Agent SDK, non `claude -p` con `stream-json`. La chat SDK passa un MCP server interno per le domande interattive. [ClaudeCodeLifeCycleService.ts](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/src/server/core/claude-code/services/ClaudeCodeLifeCycleService.ts#L190-L235)
- Il terminale è un processo shell con PTY tramite `@replit/ruspty`; i componenti di chat e terminale sono distinti. [package.json](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/package.json#L44-L50), [TerminalService.ts](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/src/server/core/terminal/TerminalService.ts#L185-L205)
- I log sono validati con schemi Zod. Una riga JSON non valida o non riconosciuta diventa un elemento di errore con il testo originale, invece di essere scartata senza avviso. [parseJsonl.ts](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/src/server/core/claude-code/functions/parseJsonl.ts#L4-L36)
- La cache registra conteggio messaggi, costo, uso token, modello e link PR per sessione; conserva questi indici fuori dai transcript canonici. [schema.ts](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/src/server/lib/db/schema.ts#L20-L45)

## Sessioni e task
- Può creare un progetto scegliendo una directory e avviando `/init`; il repository non documenta creazione automatica di worktree per progetto. [README](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/README.md#L187-L188)
- Elenca progetti e sessioni leggendo i file di Claude Code, avvia sessioni, riprende quelle esistenti e consente di continuare un processo già avviato. [README](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/README.md#L181-L188)
- I processi di sessione avviati dal Viewer restano attivi finché non vengono interrotti esplicitamente; si può continuare senza assegnare un nuovo session ID. [docs/dev.md](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/docs/dev.md#L43-L49)
- Più processi possono essere tenuti dal server, ma la loro lista è una `Ref` in memoria. Il codice non documenta un coordinatore persistente di agenti o una procedura di riattacco dopo il riavvio del server. [ClaudeCodeSessionProcessService.ts](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/src/server/core/claude-code/services/ClaudeCodeSessionProcessService.ts#L31-L49)
- Il pannello Task mostra i task nativi `TaskCreate`/`TaskUpdate`, con dipendenze e persistenza tra sessioni nel formato di Claude Code. È una vista sui task dell’agente, non una board di lavoro indipendente. [Guida ai task](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/docs/claude-code-tasks.md#L1-L47), [README](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/README.md#L199-L205)
- Include uno scheduler di messaggi: espressioni cron ricorrenti o invii una tantum, con politica per gestire sovrapposizioni e cancellazione degli invii riservati. [README](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/README.md#L193-L195), [Scheduler.ts](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/src/server/core/scheduler/domain/Scheduler.ts#L30-L76), [Scheduler.ts](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/src/server/core/scheduler/domain/Scheduler.ts#L80-L124)
- Può pianificare un `continue` un minuto dopo il reset di un rate limit, una preferenza disattivata per default. [README](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/README.md#L159-L170)
- Gli orari e la definizione dei job persistono in `~/.claude-code-viewer/scheduler/schedules.json`; all’avvio il servizio rilegge la configurazione. [config.ts](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/src/server/core/scheduler/config.ts#L15-L38), [Scheduler.ts](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/src/server/core/scheduler/domain/Scheduler.ts#L187-L196)
- Il pannello Git mostra diff, commenti inline e branch; l’utente può fare commit e push. Non è descritto un ciclo automatico di worktree, review, merge, CI e publish. [README](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/README.md#L195-L199), [GitService.ts](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/src/server/core/git/services/GitService.ts#L509-L550)

## Usabilità
- La ricerca globale supporta corrispondenze fuzzy e prefissi, navigazione da tastiera e filtri per progetto. [README](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/README.md#L181-L183)
- Si può configurare se nascondere sessioni prive di messaggi utente e se unificare sessioni con titolo uguale. [README](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/README.md#L155-L164)
- L’interfaccia copre elenco progetti, sessioni, conversazione, impostazioni e pannelli laterali. Il progetto include screenshot desktop e mobile nel repository. [README](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/README.md#L212-L230)
- Cerca nel testo delle conversazioni per progetto o globalmente con `⌘K` su macOS e `Ctrl+K` su Linux; `⌘F`/`Ctrl+F` trova testo nella sessione aperta. [README](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/README.md#L181-L183)
- Salva bozze per progetto e sessione; supporta completamento di file e comandi, input vocale, allegati e anteprima di immagini, PDF e testo. [README](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/README.md#L189-L192)
- Le opzioni di avvio sessione sono nel contesto della chat: modello, livello di ragionamento, permessi e prompt di sistema, con impostazioni per progetto. [README](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/README.md#L188-L189)
- Visualizza chiamate agli strumenti, risultato o JSON grezzo, checklist Todo, task figli, link alle PR, cambiamenti Git e richieste di approvazione nella conversazione. [README](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/README.md#L199-L207)
- Ha tema chiaro/scuro, notifiche audio e tre lingue dichiarate: inglese, giapponese e cinese semplificato. [README](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/README.md#L155-L171), [README](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/README.md#L249-L253)
- Il flusso di installazione è CLI via `npx` o npm globale; non richiede installare un’app desktop separata. [README](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/README.md#L47-L64)

## Terminale, editor, file
- La gestione limita il terminale a 10 sessioni, con buffer di output da 2 MiB e scadenza per inattività di 30 minuti. [TerminalService.ts](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/src/server/core/terminal/TerminalService.ts#L35-L37)
- Un terminale integrato nel pannello inferiore apre una shell sul computer server attraverso WebSocket e PTY; può essere disabilitato dalla configurazione. [README](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/README.md#L29-L31), [README](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/README.md#L134-L136)
- Su mobile il terminale ha controlli touch, pulsanti per i tasti speciali, incolla e navigazione a flick, introdotti nelle note di release. [CHANGELOG](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/CHANGELOG.md#L16-L27)
- Fornisce completamento file/comandi, anteprima file e allegati, elenco dei file modificati e diff; non emerge un editor di codice completo con editing visuale nel client. [README](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/README.md#L184-L191), [README](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/README.md#L199-L200)
- Il pannello Git consente commenti inline sul diff, commit, push e cambio branch locale. [README](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/README.md#L195-L199)
- Il terminale lancia la shell dell’host: non crea una worktree o un ambiente isolato per ogni sessione. Bash parte con `--restricted`, salvo configurazione che disabilita i flag restrittivi. [TerminalService.ts](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/src/server/core/terminal/TerminalService.ts#L39-L52)

- La UI è una PWA installabile su desktop o mobile e può inviare notifiche push per sessioni completate, richieste di permesso o domande. [README](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/README.md#L95-L95), [NotificationService.ts](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/src/server/core/notification/services/NotificationService.ts#L91-L125)
- Non richiede un relay cloud del produttore: l’istanza e i file restano sull’host scelto dall’utente; l’accesso remoto è tramite la rete configurata dall’utente. [README](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/README.md#L82-L95), [PRIVACY.md](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/PRIVACY.md#L5-L8)
- Offre `--base-path` per reverse proxy e `--api-only` per esporre solo API core, con cui integrare strumenti esterni. [README](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/README.md#L97-L118), [README](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/README.md#L137-L138)
- Se il servizio è esposto senza password, l’autenticazione API è disabilitata; l’accesso remoto deve quindi essere configurato esplicitamente. [README](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/README.md#L126-L153)

## Provider e protocolli
- Può usare l’ambiente della CLI Claude Code, compreso un endpoint Anthropic-compatibile configurato fuori dal Viewer; non esiste però un selettore provider autonomo. L’issue #231 usa `ANTHROPIC_BASE_URL` con DeepSeek e segnala comunque una nuova voce di log non supportata. [issue #231](https://github.com/d-kimuson/claude-code-viewer/issues/231)
- Il modello e il menu possono includere identificatori supportati dalla CLI; l’integrazione non astrae provider diversi da Claude Code. [README](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/README.md#L167-L168)
- Il provider supportato come integrazione di prodotto è Claude Code; il Viewer verifica la versione CLI e invoca l’Agent SDK. Non risultano adapter dedicati per Codex, Gemini, OpenCode o ACP. [README](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/README.md#L9-L20), [package.json](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/package.json#L44-L50)
- La modalità API key, predefinita, usa l’API Anthropic tramite Agent SDK; modello e impostazioni passano dalla CLI e dal progetto Claude Code. [README](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/README.md#L22-L27), [ClaudeCode.ts](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/src/server/core/claude-code/models/ClaudeCode.ts#L169-L208)
- In modalità subscription il Viewer disattiva invio chat, resume, approvazioni e domande via SDK; mostra invece un comando CLI da copiare e lanciare dall’utente. [README](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/README.md#L13-L27)
- La documentazione Anthropic attuale dice che chi integra l’Agent SDK in un prodotto deve usare API key o credenziali di provider cloud, e non può raccogliere o instradare token di abbonamento a nome degli utenti. Permette all’utente di autenticarsi direttamente nel binario Claude Code non modificato. Il flusso di copia del comando è coerente con questa distinzione; non equivale a una valutazione legale. [policy Anthropic](https://code.claude.com/docs/en/legal-and-compliance#authentication-and-credential-use)
- Legge la configurazione MCP esistente di Claude Code e mostra server, comandi e stato. Non è un gateway MCP generico esposto ad altri agenti. [README](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/README.md#L205-L207), [ClaudeCode.ts](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/src/server/core/claude-code/models/ClaudeCode.ts#L108-L117)

## Performance
- L’aggiornamento dal filesystem e i cambiamenti di sessione sono distribuiti ai client con SSE; la cache viene sincronizzata dal server. [docs/dev.md](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/docs/dev.md#L24-L41)
- Non dichiara benchmark di avvio, memoria o rendering. Le note di rilascio citano ottimizzazioni e virtualizzazione del diff, ma non pubblicano misure comparative. [CHANGELOG](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/CHANGELOG.md#L92-L155)
- La lista sessioni ha paginazione cursor-based e restituisce 20 sessioni per default; la ricerca testuale usa SQLite FTS5. [SessionRepository.ts](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/src/server/core/session/infrastructure/SessionRepository.ts#L73-L139), [DrizzleService.ts](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/src/server/lib/db/DrizzleService.ts#L13-L32)
- Aprire un transcript legge il JSONL completo in memoria e lo analizza riga per riga; la UI rende tutte le righe della conversazione con `.map`. [SessionRepository.ts](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/src/server/core/session/infrastructure/SessionRepository.ts#L44-L63), [ConversationList.tsx](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/src/web/app/projects/%5BprojectId%5D/sessions/%5BsessionId%5D/components/conversationList/ConversationList.tsx#L767-L780)
- Nel codice della versione esaminata non si vede virtualizzazione della lista conversazioni; il rendering su transcript molto grandi è un rischio da misurare, non una lentezza dimostrata. [ConversationList.tsx](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/src/web/app/projects/%5BprojectId%5D/sessions/%5BsessionId%5D/components/conversationList/ConversationList.tsx#L767-L780)
- La ricerca di issue per slow, memory, lag, freeze, CPU, battery e browser non ha trovato lamentele di performance verificate. Le issue #8 e #9 riportano carichi grandi, ma i commenti chiariscono che erano state aperte per errore sul repository upstream, non come feedback d’uso. [issue #8](https://github.com/d-kimuson/claude-code-viewer/issues/8), [issue #9](https://github.com/d-kimuson/claude-code-viewer/issues/9)

## Affidabilità e qualità
- Le sessioni si recuperano dai JSONL, ma il Viewer avverte che non ne crea copie; la durata dipende dalla retention configurata in Claude Code. [README](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/README.md#L232-L247)
- Il clone contiene 120 file di test `*.test.*` o `*.spec.*`; la CI esegue lint, typecheck, test, controlli di traduzione e verifica del pacchetto. [package.json](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/package.json#L18-L42), [ci.yml](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/.github/workflows/ci.yml#L14-L48)
- Il controllo visivo Playwright è snapshot/VRT, non una suite di veri flussi end-to-end. [docs/dev.md](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/docs/dev.md#L168-L191)
- I transcript persistono nei file originali; se fallisce una migrazione, la cache derivata viene ricreata. I log sorgente non vengono copiati o salvati dal Viewer. [DrizzleService.ts](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/src/server/lib/db/DrizzleService.ts#L56-L84), [README](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/README.md#L232-L247)
- Claude Code elimina di default i transcript oltre 30 giorni; quando li rimuove, spariscono anche dal Viewer. [README](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/README.md#L232-L247)
- I job pianificati sono su file, ma l’elenco dei processi attivi e le notifiche in attesa sono in memoria; non va presunta la ripresa completa dello stato attivo dopo un crash. [config.ts](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/src/server/core/scheduler/config.ts#L34-L85), [ClaudeCodeSessionProcessService.ts](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/src/server/core/claude-code/services/ClaudeCodeSessionProcessService.ts#L31-L49)

- Le release sono pacchetti npm e installazione via `npx`; non è documentato un aggiornamento automatico in-app. [README](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/README.md#L47-L64)

## Sicurezza e privacy
- Le chiavi VAPID generate per le push sono conservate in `~/.claude-code-viewer/vapid-keys.json`; le sottoscrizioni browser invece vivono in memoria del server. [NotificationService.ts](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/src/server/core/notification/services/NotificationService.ts#L22-L70), [NotificationService.ts](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/src/server/core/notification/services/NotificationService.ts#L68-L89)
- Il cookie di sessione viene generato casualmente con 32 byte e il confronto della password usa confronto a tempo costante. [auth.middleware.ts](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/src/server/hono/middleware/auth.middleware.ts#L9-L22)
- `PRIVACY.md` dichiara nessuna telemetria e nessun servizio esterno oltre all’API Anthropic; è una dichiarazione del progetto, non una misura di rete indipendente. [PRIVACY.md](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/PRIVACY.md#L1-L10)
- C’è però una discrepanza: quando si attivano le push, il server invia `web-push` all’endpoint registrato dal browser. Il payload include il tipo di notifica, un prefisso del session ID e un URL con project ID e session ID. [NotificationService.ts](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/src/server/core/notification/services/NotificationService.ts#L187-L218)
- La password è facoltativa e condivisa per l’istanza; senza `--password`/`CCV_PASSWORD` l’API non richiede autenticazione. Non risultano utenti, ruoli o OAuth di prodotto. [README](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/README.md#L126-L153)
- L’API accetta cookie di sessione o bearer password; il WebSocket del terminale controlla il cookie quando l’autenticazione è attiva. [auth.middleware.ts](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/src/server/hono/middleware/auth.middleware.ts#L34-L66), [terminalWebSocket.ts](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/src/server/terminal/terminalWebSocket.ts#L76-L94)
- Il server legge log di sessione locali e permette l’uso di una shell sull’host; `--terminal-unrestricted` toglie i flag `--restricted` a bash. Non è documentato isolamento per container o per worktree. [README](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/README.md#L134-L138), [TerminalService.ts](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/src/server/core/terminal/TerminalService.ts#L39-L52)
- L’autenticazione deve essere attivata prima di un bind su `0.0.0.0`; il README raccomanda password e HTTPS Tailscale per l’accesso remoto. [README](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/README.md#L82-L95), [README](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/README.md#L126-L153)

## Da evitare
- I log dei transcript e gli active process hanno durate diverse: non promettere che una sessione viva sopravviva automaticamente a un riavvio del server solo perché il JSONL è persistente. [SessionRepository.ts](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/src/server/core/session/infrastructure/SessionRepository.ts#L44-L63), [ClaudeCodeSessionProcessService.ts](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/src/server/core/claude-code/services/ClaudeCodeSessionProcessService.ts#L31-L49)
- Non instradare token OAuth di abbonamento attraverso l’Agent SDK; mantenere separato il login diretto nel binario CLI e usare API key per l’integrazione SDK. [README](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/README.md#L13-L27), [policy Anthropic](https://code.claude.com/docs/en/legal-and-compliance#authentication-and-credential-use)
- Non presentare come solo locale un prodotto con push esterne: qui il codice invia endpoint e payload push anche se la policy privacy dice che non ci sono altri servizi esterni. [PRIVACY.md](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/PRIVACY.md#L5-L8), [NotificationService.ts](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/src/server/core/notification/services/NotificationService.ts#L187-L218)
- Non esporre terminale e log con password disattivata o un’unica password condivisa; non equivale ad account distinti o autorizzazioni per ruolo. [README](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/README.md#L126-L153)
- Non affidare la compatibilità dei log a uno schema che non conserva gli elementi sconosciuti: l’issue #231 mostra che nuovi record possono interrompere la lettura. [issue #231](https://github.com/d-kimuson/claude-code-viewer/issues/231)
- Non dichiarare prestazioni su transcript grandi senza misurare memoria e rendering; il codice legge l’intero JSONL e renderizza tutte le righe. [SessionRepository.ts](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/src/server/core/session/infrastructure/SessionRepository.ts#L44-L63), [ConversationList.tsx](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/src/web/app/projects/%5BprojectId%5D/sessions/%5BsessionId%5D/components/conversationList/ConversationList.tsx#L767-L780)
- Non chiamare scheduler o task viewer una pipeline multi-agente: qui mancano worktree isolate e orchestrazione automatica di review, merge e publish. [README](https://github.com/d-kimuson/claude-code-viewer/blob/9367cf006be9965c954e6cd36526f2195dce67ea/README.md#L193-L207)
