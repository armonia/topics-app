Give it a board. Walk away.

Topics does not just watch agents work — it puts them to work. Drop a task on the board and an agent picks it up in its own git worktree, so parallel agents never fight over your checkout.

  1. 1

    You write the task

    What should happen, where to look, how it is verified. A vague task comes back vague.

  2. 2

    An agent takes it

    Dispatched into an isolated worktree on its own branch. Several agents run at once without collisions.

  3. 3

    It delivers evidence

    Committed work, a summary, and a screenshot or video of the thing actually working — then it moves itself to review.

  4. 4

    You approve

    Read the diff, approve, land it into main. Publishing is always a separate, deliberate click — never automatic.

Every session starts in ultracode

Launched from a plain shell, Claude Code falls back to low effort. Topics passes --effort explicitly, so sessions start at the top tier — with a per-topic selector when you want to spend less on a small job.

Sub-agents stay visible

When an agent spawns its own fleet, the children show up in the session tree instead of vanishing into a pipe. You can see what each one is doing and what it is spending.

Nothing lands behind your back

Approve accepts the work. Landing merges it locally. Publishing pushes. Three separate decisions, three separate clicks — because "done" should mean you said so.

Organize

Structure that survives a restart — and a second machine.

  • Topics, not tabs — group sessions by project or intent; each remembers its terminal, files and conversation.
  • Projects side by side — several whole projects open at once in a resizable split grid.
  • Spaces & split panes — split any pane, drag tabs between groups, detach a window.
  • Layout that persists — panes, splits and tabs come back exactly as you left them.
  • Tab sync across devices — open the same workspace on another machine and find it in the same shape.
  • Command palette & shortcuts — everything reachable from the keyboard, including reopen-closed-tab.

Run

The agent, the server and the page it renders — in one place.

  • Embedded terminals — run Claude Code, Codex or any CLI agent and watch it work.
  • Lossless reattach — reload the app, close the laptop: the session is still there, scrollback intact.
  • Browser pane — a real browser per topic for localhost, docs, or letting the agent drive the page.
  • Processes & scripts — start dev, test, build from the sidebar and keep their logs.
  • Git worktrees — isolated checkouts per task, named and garbage-collected for you.
  • Cron jobs & webhooks — recurring work and outside triggers, without leaving the app.

See

What the agents are doing, and what it is costing you.

  • Agent monitoring — every session's state at a glance, with a native notification when one finishes or needs you.
  • Heartbeats & history — a timeline per session, and a viewer to read back what happened.
  • Context inspector — see what is filling the window, toggle sources, edit per-topic memory.
  • Dashboard — throughput, cycle time, token spend and an agent leaderboard.
  • Per-pane resource usage — which tab is eating your RAM, not just how much the app uses.
  • Activity feed & journal — a live stream of what happened, and a daily digest.

Ship

From a card on a board to a commit on main.

  • Kanban board — tasks, subtasks, priorities, tags, dependencies and drag-drop.
  • Agent dispatch — assign a card to an agent and it starts working, in its own worktree.
  • Approval workflow — review gates, delivery evidence, reject-with-notes that sends the agent back.
  • Diff review — read the change in-app before you accept it.
  • File explorer & editor — tree, search, syntax-highlighted editing and git status inline.
  • Land, then publish — merge locally when you are ready; pushing stays a separate decision.

Is the free version crippled?

No. The board, the agents, the worktrees, the dashboard — all of it is in the free app, under MIT. If you only ever work on one machine, there is nothing here to buy.

Do I pay you for tokens?

Never. Topics talks to Anthropic with your key or your subscription, and that bill stays between you and them. We do not resell inference or take a cut.

What happens if I stop paying?

The app keeps working. You lose sync and remote access; every topic, board and terminal stays on your disk exactly as it was.

Can I self-host the Pro features?

Remote access already works with your own tunnel and your own auth — that path is open source and free. Pro is the hosted version for people who would rather not run it.
