        one window, every surface
        
Everything an agent session needs, side by side.

        
No tab-juggling, no lost context. Each topic carries its own project, terminal, browser and board.

      

      

        

          

          
Topics, not tabs

          
Group related agent sessions by project or intent. Switch context in one keystroke; every topic remembers its terminal, files and conversation.

        

        

          

          
Live terminal

          
Run Claude Code, Codex or any CLI agent in an embedded terminal and watch it work in real time.

        

        

          

          
Browser inside

          
A real Chromium pane per topic. Preview localhost, read docs, let agents drive the page.

        

        

          

          
Kanban tasks

          
Turn an agent's plan into a board. Track what is queued, running and shipped per topic.

        

        

          

          
Agent monitoring

          
See every running session at a glance: status, tokens, context budget. Step in when needed.

        

        

          

          
Open and yours

          
MIT-licensed, local-first, zero telemetry. Bring your own keys and your own agents. Everything runs on your machine.
