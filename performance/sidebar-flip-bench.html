Sidebar push — FLIP (transform) vs animated paddingLeft

Reproduces the Topics layout that makes the sidebar collapse/expand PUSH expensive: a #main-content (contain:layout style, overflow:hidden) whose paddingLeft reserves the sidebar column, an inner flip layer (flex col), then N panes each holding an xterm-like 80×24 DOM grid. Measures the per-op forced-reflow cost of changing paddingLeft (the OLD animated-push approach — a LAYOUT property) vs the flip layer's transform:translateX (the FLIP — a COMPOSITOR property). ~12 ops = one 200ms slide at a 60fps 16.6ms/frame budget. Lock-proof: this is JS + layout timing (runs even with the screen locked); it does NOT measure composited frames. Both results are engine-universal (padding is layout, transform is compositor in WebKit and Chromium alike). Open in any browser; click Run.
